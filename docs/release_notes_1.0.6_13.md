# Balaji Points – Release Notes

## Version 1.0.6 (Build 13)

**Release date:** March 2026

---

### What's new

**For carpenters**
- **Offers on Home** – Offer banners added by admin now show correctly on the home screen. Tap **View Offer** to see the full offer image.
- **Profile** – Profile photo and name update right away on Home and Profile after saving. Edit profile fields are saved and pre-filled when you open Edit Profile again.
- **Add Bill** – Improved layout so the Submit button and content stay above the bottom tab bar; same navigation bar style as other screens.
- **Products & Cart** – Products list, cart, and place order work correctly with updated permissions.

**For admin**
- **Carpenter list export** – Export the full carpenter (user) list to PDF from the Users screen. PDF includes carpenter name, mobile number, points, tier, and date joined, with your store branding.
- **Bill approval** – More reliable approval of bills from the admin panel.
- **Bill history** – Export filtered bill history to PDF (existing feature; refinements included).
